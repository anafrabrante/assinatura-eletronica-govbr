# Testes e Validação de Requisitos (gov.br)

Trabalho da disciplina de Engenharia de Software

Integrantes: Ana Paula Freire e Vitoria Nunes

## Resumo
Este repositório documenta a especificação de requisitos, critérios de aceitação, planejamento, execução de testes e rastreabilidade aplicados ao fluxo de **Assinatura Eletrônica do Portal gov.br** (`https://assinador.iti.br`), abrangendo o envio de documentos, posicionamento visual, autorização via aplicativo, download e verificação no serviço **VALIDAR**.
