**Matriz de Rastreabilidade**


A matriz de rastreabilidade relaciona os requisitos funcionais, os critérios de aceitação e os casos de teste realizados, demonstrando que as funcionalidades foram verificadas

| Requisito | Critério de aceitação | Caso(s) de teste |
|---|---|---|
| RF01 | O sistema deve aceitar documentos válidos | CT01 |
| RF01 | O sistema deve permitir o envio de até cinco documentos | CT03 |
| RF01 | O sistema deve impedir o envio de mais de cinco documentos | CT04 |
| RF01 | O sistema deve identificar arquivos corrompidos | CT05 |
| RF01 | O sistema deve rejeitar arquivos vazios | CT06 |
| RF01 | O sistema deve rejeitar formatos não permitidos | CT07 |
| RF01 | O sistema deve impedir o envio de arquivos acima do limite de tamanho | CT08 |
| RF02 | O sistema deve impedir o posicionamento da assinatura fora dos limites do documento | CT11 |
| RF03 | O sistema deve permitir a realização da assinatura com autorização válida | CT02 |
| RF03 | O sistema deve permitir assinatura sem representação visual | CT12 |
| RF03 | O sistema deve rejeitar códigos de autorização incorretos | CT13 |
| RF04 | O sistema deve disponibilizar o documento assinado para download | CT09 |
| RF05 | O serviço de validação deve reconhecer a autenticidade da assinatura | CT10 |

**Legenda**

- **RF:** Requisito Funcional
- **CT:** Caso de Teste
