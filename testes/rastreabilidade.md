**Matriz de Rastreabilidade**

A matriz de rastreabilidade relaciona os requisitos identificados aos critérios de aceitação e aos casos de teste responsáveis por verificá-los

| Requisito | Critério de aceitação | Caso(s) de teste |
|---|---|---|
| RF01 | Aceitar documentos em formatos permitidos | CT01 |
| RF01 | Rejeitar formatos não permitidos | CT07 |
| RF01 | Rejeitar arquivos acima do limite de tamanho | CT08 |
| RF01 | Identificar arquivos corrompidos | CT05 |
| RF01 | Rejeitar arquivos vazios | CT06 |
| RF01 | Respeitar o limite de quantidade de documentos | CT03, CT04 |
| RF02 | Permitir o posicionamento da assinatura | CT02 |
| RF02 | Impedir posicionamento fora dos limites do documento | CT11 |
| RF02 | Permitir assinatura sem representação visual | CT12 |
| RF03 | Permitir assinatura com código válido | CT02 |
| RF03 | Rejeitar código de autorização incorreto ou expirado | CT13 |
| RF04 | Disponibilizar o documento assinado para download | CT09 |
| RF05 | Reconhecer a assinatura no serviço VALIDAR | CT10 |
