**Checklist de Testes**

- [ ] Verificar se um documento válido pode ser selecionado
- [ ] Verificar se a assinatura de um documento individual funciona
- [ ] Verificar se é possível enviar até cinco documentos simultaneamente
- [ ] Verificar se o sistema impede o envio de mais de cinco documentos
- [ ] Verificar se arquivos corrompidos ou vazios são identificados
- [ ] Verificar se arquivos acima do limite permitido são rejeitados
- [ ] Verificar se formatos não suportados são rejeitados
- [ ] Verificar se o documento assinado pode ser baixado e validado
- [ ] Verificar se a assinatura permanece presente após download
